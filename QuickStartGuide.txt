MarvinOS Quick-Start

Local, GPU-accelerated AI stack — LLMs, TTS, Web Search, and Image Generation. Fully self-hosted, reproducible, offline-ready.

Features

Local LLM inference (Ollama)

GPU-accelerated (NVIDIA, 8GB+)

Chat UI (Open WebUI)

Local TTS (OpenAI-compatible)

Private Web Search (SearXNG)

Stable Diffusion image generation (Automatic1111)

One-shot config & model pull jobs

Persistent data outside repo: ../MarvinOS_Data

Quick Setup
git clone https://github.com/MarvinOS-online/fitlab-core.git
cd fitlab-core
docker compose up --build


One-shot containers run and exit

Model pulls preload automatically

Access UI:

HTTP: http://localhost

HTTPS: https://localhost

Debug: http://localhost:8080

Key Services
Service	Port	Function
ollama	11434	GPU LLM runtime
open-webui	8080	LLM chat + TTS + Image generation
stable-diffusion	7860	Local image API
openai-edge-tts	5050	Local TTS engine
searxng	8081	Private web search
ingress (Nginx)	80/443	HTTPS proxy
Environment Highlights

Ollama GPU config (default, modern GPUs):

OLLAMA_FLASH_ATTENTION=1
OLLAMA_KV_CACHE_TYPE=q4_0
OLLAMA_GPU_LAYERS=40


Stable Diffusion in Open WebUI:

ENABLE_IMAGE_GENERATION=True
IMAGE_GENERATION_ENGINE=automatic1111
AUTOMATIC1111_BASE_URL=http://stable-diffusion:7860
AUTOMATIC1111_API_AUTH=username:stable-diffusion-key
IMAGE_GENERATION_MODEL=v1-5-pruned-emaonly


TTS:

AUDIO_TTS_ENGINE=openai
AUDIO_TTS_OPENAI_API_KEY=openai-edge-tts-key
AUDIO_TTS_OPENAI_API_BASE_URL=http://openai-edge-tts:5050


Web Search:

ENABLE_WEB_SEARCH=true
WEB_SEARCH_ENGINE=searxng
SEARXNG_QUERY_URL=http://searxng:8080/search?q=<query>

Common Commands
docker compose restart        # Restart stack
docker compose down           # Stop all
docker compose logs -f open-webui
docker compose logs -f ollama
docker compose up pull-llm-ollama-yourmodel  # Pull models

Security
