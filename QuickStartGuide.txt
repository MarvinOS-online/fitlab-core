MarvinOS Quick-Start

Local, GPU-accelerated AI stack — LLMs, RAG, TTS, Web Search, and Image Generation.
Fully self-hosted, reproducible, and offline-ready.

✨ Features

Local LLM inference (Ollama)

Retrieval-Augmented Generation (RAG) with vector database

GPU-accelerated (NVIDIA, 8GB+ recommended)

Chat UI (Open WebUI)

Local TTS (OpenAI-compatible)

Private web search (SearXNG)

Stable Diffusion image generation (Automatic1111)

One-shot configuration containers

Persistent data outside repo: ../MarvinOS_Data

🚀 Quick Setup
git clone https://github.com/MarvinOS-online/fitlab-core.git
cd fitlab-core
docker compose up --build


What happens:

One-shot config containers run and exit

Core services start automatically

All data persists across rebuilds

🌐 Access UI

HTTP: http://localhost

HTTPS: https://localhost

Debug (direct): http://localhost:8080

🧠 Key Services
Service	Port	Function
ollama	11434	GPU LLM runtime + embeddings
open-webui	8080	Chat UI + RAG + TTS + image generation
qdrant	6333	Vector DB for RAG
stable-diffusion	7860	Local image generation API
openai-edge-tts	5050	Local TTS engine
searxng	8081	Private web search (debug)
ingress (Nginx)	80/443	HTTPS reverse proxy
🧠 RAG (Retrieval-Augmented Generation)

RAG is enabled by default and fully local.

How it works:

Upload documents in Open WebUI

Text is embedded locally via Ollama

Embeddings are stored in Qdrant

Relevant context is retrieved per query

Responses include citations

RAG Configuration:

Vector DB: Qdrant

Embedding engine: Ollama

Embedding model: nomic-embed-text:v1.5

Citations: Enabled

Storage: Persistent on disk

⚙️ Environment Highlights
Ollama GPU config (modern GPUs)
OLLAMA_FLASH_ATTENTION=1
OLLAMA_KV_CACHE_TYPE=q4_0
OLLAMA_GPU_LAYERS=40

Stable Diffusion (Open WebUI)
ENABLE_IMAGE_GENERATION=True
IMAGE_GENERATION_ENGINE=automatic1111
AUTOMATIC1111_BASE_URL=http://stable-diffusion:7860
AUTOMATIC1111_API_AUTH=username:stable-diffusion-key
IMAGE_GENERATION_MODEL=v1-5-pruned-emaonly

TTS
AUDIO_TTS_ENGINE=openai
AUDIO_TTS_OPENAI_API_KEY=openai-edge-tts-key
AUDIO_TTS_OPENAI_API_BASE_URL=http://openai-edge-tts:5050

Web Search
ENABLE_WEB_SEARCH=true
WEB_SEARCH_ENGINE=searxng
SEARXNG_QUERY_URL=http://searxng:8080/search?q=<query>

📥 Pulling Ollama Models (Correct Way)

Models are managed inside the Ollama container.

Pull a model
docker compose exec ollama ollama pull llama3.2:3b


Examples:

docker compose exec ollama ollama pull mistral:7b
docker compose exec ollama ollama pull qwen2.5:7b
docker compose exec ollama ollama pull nomic-embed-text:v1.5

List models
docker compose exec ollama ollama list


Models are stored in:

../MarvinOS_Data/ollama
