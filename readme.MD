Services Explained
1. configure_ingress

A one-shot configuration container that:

Copies curated Nginx configs and HTML assets
Generates or installs SSL certificates
Writes everything into persistent volumes under MarvinOS_Data
This container runs once and exits.

2. ingress (Nginx)

Acts as the public entry point.
Listens on 80 / 443
Uses configs generated by configure_ingress
Serves static HTML if present
Proxies traffic to Open WebUI
Includes a healthcheck (nginx -t)

3. ollama

Local LLM runtime with GPU support.
Exposes port 11434
Uses NVIDIA GPUs (gpus: all)
Persists models under:

../MarvinOS_Data/ollama

Automatically binds to 0.0.0.0

4. Model Pull Jobs (pull-llm-*)

These are one-time jobs that pre-download models into Ollama:
llama3
mistral
codellama
neural-chat
llama2
phi
wizard-math
openchat
tinyllama

They:

Depend on Ollama

Run once

Exit after the model is downloaded
You can remove or add models safely.

5. open-webui

The primary LLM chat interface.

Runs on port 8080 (internally)
Proxied by Nginx for HTTPS access
Auth and signup enabled
Connected directly to Ollama
Persistent backend data stored in:

../MarvinOS_Data/open-webui


Environment highlights:

OLLAMA_BASE_URL=http://ollama:11434
DEFAULT_MODEL=llama3.2:3b
Auth enabled by default

6. openai-edge-tts

Optional local TTS service compatible with Open WebUI.
Runs on port 5050
Used for speech synthesis
Does not require OpenAI cloud access
Directory Layout

Expected structure:

.
├── docker-compose.yml
├── Dockerfile.NginxConfig
├── Dockerfile.pull-model
├── nginx/
│   ├── etc/
│   └── html/
└── ../MarvinOS_Data/
    ├── nginx/
    ├── certs/
    ├── html/
    ├── ollama/
    └── open-webui/


Important: MarvinOS_Data lives outside the repo to preserve data across rebuilds.

Prerequisites

Docker 24+
Docker Compose v2
NVIDIA GPU + drivers
NVIDIA Container Toolkit installed
Linux host recommended

Verify GPU support:

docker run --rm --gpus all nvidia/cuda:12.2.0-base nvidia-smi

First-Time Setup
1. Build and run everything

docker compose up --build

2. Wait for model pulls to complete

Model pull containers will exit automatically once finished.

3. Access the UI

HTTP: http://localhost
HTTPS: https://localhost
Direct UI (debug): http://localhost:8080

Common Operations

Restart the stack
docker compose restart

Stop everything
docker compose down

Pull additional models
Add another pull-llm-* service and run:
docker compose up pull-llm-ollama-yourmodel

View logs

docker compose logs -f open-webui
docker compose logs -f ollama
docker compose logs -f ingress

Security Notes

SSL certificates are self-signed by default
Auth is enabled in Open WebUI
Secrets should be replaced before public exposure:

WEBUI_SECRET_KEY
API_KEY for TTS

This stack is not hardened for public internet by default

Intended Use

This stack is ideal for:

Local AI experimentation
Secure internal LLM access
GPU-accelerated inference
MarvinOS development and integration
Offline or air-gapped environments
